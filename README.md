# Survive60sec

縦スクロールのモバイル向けシューティング（プロトタイプ）。
プレイヤーは 1 分（60 秒）あらゆる攻撃を避け切ることを目指します。

目的
- 操作性重視の縦画面 STG のプロトタイプを Godot 4 で作成します。

動作確認手順（ローカル）
1. Godot 4.x をインストールします（https://godotengine.org）。
2. リポジトリをクローンします:
   git clone https://github.com/psycardmaster/Survive60sec.git
3. Godot でプロジェクトフォルダを開きます（project.godot を指定）。
4. シーン `res://scenes/Main.tscn` を実行して操作を確認します（エディタで再生）。

操作（プロトタイプ）
- タッチ/ドラッグ、またはマウス左クリックでプレイヤーが指の位置へ移動します。
- 自動攻撃（現状は未実装、後で追加します）。
